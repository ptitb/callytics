# Config Reference

Environment variables below follow repository `.env.example`. Secrets are generated by `scripts/install.sh`.

| Variable | Default | Required | Description |
| --- | --- | --- | --- |
| `DB_HOST` | `localhost` | Yes | PostgreSQL host used by backend and stasis. Change when DB is not local host network. |
| `DB_PORT` | `5432` | Yes | PostgreSQL TCP port. Wrong value blocks DB connections/migrations. |
| `DB_NAME` | `callytics` | Yes | Database name used for all application tables. |
| `DB_USER` | `callytics` | Yes | Database login user. Must match DB role permissions. |
| `DB_PASS` | generated by `scripts/install.sh` | Yes | Database password for `DB_USER`. Wrong value breaks startup and backup/restore DB commands. |
| `REDIS_HOST` | `localhost` | Yes | Redis host for pub/sub, queue state, campaign/callback signaling, streams. |
| `REDIS_PORT` | `6379` | Yes | Redis TCP port. Wrong value disables runtime event flow and queue state operations. |
| `ARI_URL` | `http://127.0.0.1:8088` | Yes | Asterisk ARI base URL used by stasis. |
| `ARI_USER` | `callytics` | Yes | ARI username for API auth. |
| `ARI_PASS` | generated by `scripts/install.sh` | Yes | ARI password for API auth. |
| `ARI_APP` | `callytics` | Yes | Stasis application name Asterisk routes calls into. |
| `AMI_HOST` | `127.0.0.1` | Yes | Asterisk AMI host used by backend config/diagnostics tooling. |
| `AMI_PORT` | `5038` | Yes | Asterisk AMI port. Rendered into `manager.conf` when the asterisk container starts. |
| `AMI_USER` | `callytics` | Yes | AMI login username. |
| `AMI_PASS` | generated by `scripts/install.sh` | Yes | AMI login password. |
| `BACKEND_PORT` | `3001` | Yes | HTTP port for NestJS backend service. |
| `NODE_ENV` | `development` | No | Node runtime environment mode. |
| `RECORDINGS_INTERNAL_TOKEN` | generated by `scripts/install.sh` | Yes | Shared token for internal recording persistence endpoint (`/recordings/internal`). |
| `HOST_IP` | `127.0.0.1` | Yes | Host machine IP used in config/provisioning responses and VPN endpoint fallback logic. |
| `SIP_PORT` | `5080` | Yes | SIP listening port advertised by backend host config endpoint. |
| `RTP_PORT_START` | `10000` | No | First RTP port for the initial `rtp.conf`. Afterwards managed in Settings > Media (RTP). |
| `RTP_PORT_END` | `20000` | No | Last RTP port for the initial `rtp.conf`. |
| `SIP_TLS_PORT` | `5081` | No | SIP over TLS port (TCP). |
| `SIP_TLS_HOSTNAME` | empty | No | DNS name softphones connect to. Used for the certificate file names and TLS provisioning URIs. |
| `SIP_TLS_CERT_DIR` | empty | No | Host directory with `<SIP_TLS_HOSTNAME>.crt` and `.key`, mounted read-only. TLS stays disabled while empty. |
| `SIP_TLS_CERT_FILE` / `SIP_TLS_KEY_FILE` | empty | No | Override the certificate and key file names inside `SIP_TLS_CERT_DIR`. |
| `SIP_TLS_WATCH_INTERVAL` | `3600` | No | Seconds between checks for a renewed certificate. A change reloads `res_pjsip`. |
| `WEB_BIND_ADDR` | `127.0.0.1` | No | Bind address of the web UI (nginx, port 3000). |
| `BACKEND_BIND_ADDR` | `127.0.0.1` | No | Bind address of the backend API. |
| `ARI_BIND_ADDR` | `127.0.0.1` | No | Bind address of Asterisk HTTP (ARI and the WebRTC WebSocket, port 8088). Rendered into `http.conf` and the WebSocket transport. |
| `UPLOAD_MAX_MB` | `100` | No | Maximum upload size in MB for nginx (`client_max_body_size`) and the audio upload endpoint. |
| `DIRECT_OUTBOUND_TIMEOUT_MS` | `30000` | No | How long a direct outbound call (external number or `#` prefix) waits for the provider to answer. |
| `PUID` | `1000` | No | WireGuard container runtime UID (linuxserver image setting). |
| `PGID` | `1000` | No | WireGuard container runtime GID (linuxserver image setting). |
| `TZ` | `UTC` | No | Container timezone (used by WireGuard container and schedule context). |

## Notes

- Variables `VPN_PUBLIC_IP` and `WIREGUARD_SERVERURL` are used in VPN runtime/compose logic, but they are not present in `.env.example` at repository root.
